# Portal Layanan Akademik — Universitas Pattimura Halaman web satu halaman untuk membantu mahasiswa memahami layanan administrasi akademik dan mengisi formulir permohonan. Dibuat dengan HTML5 dan CSS3 murni, tanpa JavaScript, framework, backend, database, atau aset dari domain luar. - Demo: [https://nabielbreemer-art.github.io/tugas-portal-akademik/](https://nabielbreemer-art.github.io/tugas-portal-akademik/) - Repository: [https://github.com/nabielbreemer-art/tugas-portal-akademik](https://github.com/nabielbreemer-art/tugas-portal-akademik) Portal ini memakai identitas Universitas Pattimura, Ambon. Alamat gedung dan alamat email layanan pada halaman bersifat contoh, sesuaikan dengan data resmi kampus sebelum dipublikasikan. ## Struktur proyek ```text tugas-portal-akademik/ ├── index.html ├── css/ │ └── styles.css ├── img/ │ └── logo.png ├── evidence/ └── README.md ``` Folder `img/` berisi logo universitas. Folder `evidence/` berisi screenshot hasil pengujian. ## Keputusan desain - **Warna:** biru tua dan biru digunakan untuk memberi kesan tepercaya dan mudah dikenali; latar biru pucat memisahkan bagian tanpa mengurangi keterbacaan. Warna hijau kebiruan menandai informasi layanan pendukung. - **Breakpoint:** halaman dimulai dari satu kolom; pada lebar 42rem alur dan kartu menjadi dua/tiga kolom, lalu pada 68rem bagian layanan menjadi empat kolom dan formulir menggunakan dua kolom. Titik perubahan mengikuti ruang yang dibutuhkan konten, bukan nama perangkat. - **Grid dan Flexbox:** CSS Grid mengatur kumpulan alur, kartu layanan, pilihan radio, serta pembagian formulir. Flexbox digunakan untuk navigasi, identitas portal, tombol, dan kelompok informasi yang perlu membungkus secara alami. - **Elemen semantik:** `header`, `nav`, `main`, `section`, `article`, `form`, `fieldset`, `legend`, `address`, dan `footer` menjelaskan tujuan konten. Judul mengikuti urutan `h1` → `h2` → `h3`. Satu tautan lewati ke konten utama membantu navigasi keyboard. - **Formulir:** validasi menggunakan atribut HTML bawaan. Formulir adalah demonstrasi tampilan; tanpa server, pengiriman tidak menyimpan atau meneruskan permohonan. - **Gerakan:** transisi singkat digunakan pada hover dan dihentikan atau dikurangi saat preferensi `prefers-reduced-motion` aktif. ## Rasio kontras warna utama Rasio dihitung dengan rumus WCAG untuk pasangan teks dan latar yang digunakan. Alasannya: logo berada di dalam tautan yang sudah punya nama jelas lewat `aria-label="Universitas Pattimura, beranda"`, dan nama kampus sudah ada sebagai teks di sebelahnya. Alt yang bermakna akan membuat pembaca layar membacakan informasi yang sama dua kali. - **Ikon SVG inline** (jam, panah, dokumen, kunci, dan lainnya) hanya bersifat dekoratif, diberi `aria-hidden="true"` dan `focusable="false"` agar tidak menambah pengumuman atau titik fokus yang tidak berguna. - Tidak ada gambar informatif lain. Bila ditambahkan kemudian, sertakan alt yang bermakna. ## Screenshot di folder `evidence/` | Berkas | Isi | |---|---| | `360px.png` | Tampilan halaman pada lebar viewport 360px. | | `768px.png` | Tampilan halaman pada lebar viewport 768px. | | `1280px.png` | Tampilan halaman pada lebar viewport 1280px. | | `elements.png` | Panel Elements: struktur DOM semantik dan CSS (Flexbox/Grid) pada form. | | `network.png` | Panel Network setelah reload; tidak ada resource gagal atau 404. | | `accessibility.png` | Accessibility tree dan properti Name, Role, Required pada field email. | | `lighthouse.png` | Hasil Lighthouse mobile: Accessibility 100, Best Practices 100, SEO 100, Performance 86. | | `validasi-kosong.png` | Form dikirim kosong; setiap field wajib menampilkan pesan error. | | `validasi-email.png` | Email `abc` ditolak dengan pesan format email. | | `validasi-berhasil.png` | Form terisi data valid. | ## Pengujian manual 1. Buka `index.html` di browser. 2. Tekan `Tab` dari awal halaman. Pastikan tautan skip muncul saat fokus, urutan fokus logis, dan semua kontrol dapat dicapai. 3. Uji layout pada lebar 360px, 768px, dan 1280px melalui Responsive Mode. Pastikan tidak ada gulir horizontal. 4. Reload halaman dengan panel Network terbuka. Pastikan stylesheet berhasil dimuat dan tidak ada 404. 5. Periksa Accessibility tree, label formulir, hierarki heading, dan tautan. 6. Jalankan Lighthouse dan simpan bukti hasilnya ke folder `evidence/`. 7. Coba kirim formulir dengan kolom kosong dan format NIM yang tidak sesuai. Browser seharusnya menampilkan validasi bawaan. Formulir ini tidak menyimpan atau mengirim data karena tidak memiliki backend. ## Menjalankan dan menerbitkan ### Lokal Buka `index.html` langsung di browser. Tidak diperlukan instalasi atau perintah build. ### GitHub Pages Situs ini diterbitkan lewat GitHub Pages dari branch `main` (folder root). Untuk menerbitkan sendiri: unggah isi folder proyek ke repository GitHub, buka **Settings → Pages**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, lalu simpan. Tidak diperlukan perintah build. Tautan hasil publikasi: https://nabielbreemer-art.github.io/tugas-portal-akademik/
